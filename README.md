# 📚 Deep Learning Application Repository

Welcome to my Deep Learning Application repository! This repository contains the code and resources developed for a university examination in Deep Learning. It showcases various concepts, models, and practical applications covered throughout the course.

## 🔬 Laboratory Sessions Overview

This section outlines the content and objectives of each laboratory session. Each lab focuses on a specific aspect of Deep Learning, building upon previous concepts.

### **Lab 1: Introduction to Neural Networks and Basic Architectures**

* **Objective**: This laboratory introduces the fundamental building blocks of neural networks. We explore basic concepts such as activation functions, loss functions, optimizers, and the training process.
* **Key Topics Covered**:
    * Perceptrons and Multi-Layer Perceptrons (MLPs)
    * Forward and backward propagation
    * Gradient Descent variants (e.g., SGD, Adam)
    * Introduction to a Deep Learning framework (e.g., TensorFlow/PyTorch)
* **Expected Files/Folders**:
    * `lab1_notebook.ipynb` (Jupyter notebook with code and explanations)
    * `data/lab1_data.csv` (Sample dataset used in Lab 1)
* **Instructions**: Run the Jupyter notebook to replicate the experiments and understand the core concepts.

### **Lab 2: Convolutional Neural Networks (CNNs) for Image Classification**

* **Objective**: This lab delves into Convolutional Neural Networks (CNNs), which are particularly effective for image processing tasks. We design and train CNN models for image classification.
* **Key Topics Covered**:
    * Convolutional layers, pooling layers, and fully connected layers
    * Architectures like LeNet, AlexNet (simplified versions)
    * Techniques for image data preprocessing and augmentation
    * Transfer learning concepts (brief introduction)
* **Expected Files/Folders**:
    * `lab2_cnn_classification.ipynb`
    * `models/lab2_best_model.h5` (Saved model weights)
* **Instructions**: Experiment with different CNN architectures and hyperparameters to improve classification accuracy on a chosen dataset (e.g., CIFAR-10, MNIST).

### **Lab 3: Recurrent Neural Networks (RNNs) for Sequence Modeling**

* **Objective**: This laboratory focuses on Recurrent Neural Networks (RNNs), suitable for processing sequential data such as text or time series. We explore their application in tasks like sentiment analysis or sequence prediction.

    * Vanilla RNNs, LSTMs (Long Short-Term Memory), and GRUs (Gated Recurrent Units)
    * Sequence embedding techniques
    * Handling variable-length sequences
    * Applications in Natural Language Processing (NLP) or time series forecasting

## 🚀 Getting Started

To run the code in this repository, ensure you have the necessary environment set up.

1.  **Clone the repository**:
    ```bash
    git clone [https://github.com/France020800/DL-application.git](https://github.com/France020800/DL-application.git)
    cd DL-application
    ```
2.  **Install dependencies**: It is highly recommended to use a virtual environment.
    ```bash
    pip install -r requirements.txt
    ```
    (You might need to create a `requirements.txt` file listing all necessary libraries, e.g., `tensorflow`, `pytorch`, `numpy`, `pandas`, `matplotlib`, `scikit-learn`, etc.)
3.  **Navigate to a lab directory** and open the Jupyter notebook:
    ```bash
    jupyter notebook
    ```
